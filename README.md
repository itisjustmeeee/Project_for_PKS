# Проект по Программированию корпоративных систем - Консольный Paint (для проестых ASCII-изображений)

## Краткое описание

Данный проект представляет собой консольное приложение, разработанное на языке C++. С помощью него можно рисовать простые фигуры на текстовом холсте с использованием ASCII-символов.

## Что реализовано в проекте (на данный момент)

 - создание холста заданных размеров
 - рисование точки с выбором символа
 - рисование линии с выбором символа
 - полная очистка холста
 - отображение полученного изображения в консоли

## Сборка проекта

### Требования

1. CMake версии 3.10 и выше
2. Компилятор с поддержкой C++ 17

### Сборка

```
cmake -S . -B build
cmake --build build
```

## Запуск проекта

```
cd build
./target_exec
```
